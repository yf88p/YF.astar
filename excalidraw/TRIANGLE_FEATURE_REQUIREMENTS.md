# Triangle Tool Benchmark Requirements

Implement a first-class Excalidraw triangle drawing tool.

The triangle must be a native element type named `triangle`, selectable from the toolbar, drawable on the canvas, styleable like other filled geometric shapes, rendered in interactive and SVG/static export paths, serializable/deserializable, and covered by tests.

Do not implement it as an arrowhead, SVG sticker, library item, group of lines, or toy replacement app.
